# Images

Drop the real Victoria Cottage photography into this folder using the filenames below. Each one is already wired up in `index.html` inside a `.placeholder` block — once the file exists, replace the placeholder `<div class="placeholder">…</div>` with a standard `<img src="images/FILENAME" alt="…">` and the layout will not need to change.
